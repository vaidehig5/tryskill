
## Purpose

TrySkill is a web application designed to help users discover and try new hobbies through short, beginner-friendly tutorial videos. Users can browse different hobby categories and find activities that can be completed in as little as 5–15 minutes. The app is designed to make exploring new interests more accessible and engaging by combining the visual discovery of platforms like Netflix and Instagram with progress tracking and streaks.

## Functionality

The current prototype focuses on the application's user interface and overall user experience. It includes templates for:

* Home page with featured and recommended activities
* Explore page for browsing hobby categories
* Activity pages for individual tutorials
* My Hobbies page for tracking explored activities
* Profile page for user information and progress

Planned functionality includes activity search and filtering, tutorial videos, activity completion tracking, exploration streaks, achievements, and personalized recommendations.
